# FastAPI backend

This folder contains the application's API (`app/`). Rice-count experiments live in [`../rice_count_pipeline/`](../rice_count_pipeline/README.md); their common photos, review assets, and prepared datasets are stored in the repository-level `../data/rice_count/` tree and shared by all methods.

Run the application using the repository-root instructions in `../README.md`. Do not place new experiment photos or generated model artifacts under this backend folder.

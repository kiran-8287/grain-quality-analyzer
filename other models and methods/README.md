# Other models and methods

This is the archive for retired or experimental code and assets. The live website does not import anything from this directory. The active computer-vision method remains in the repository root at `rice_analysis_method/`.

## Archive map

- `methods/` — previous and experimental classical image-processing methods, including prior proxy evaluation material.
- `models/` — experimental trained-model work and legacy pipeline modules/configuration.
- `previous_application/` — inactive backend endpoints/services and frontend components.
- `data_and_runs/` — retained datasets, evaluation inputs, and historical run outputs. Large image data is intentionally ignored by Git.
- `research/` — validation tools, reports, monitoring utilities, and prior test assets.

Archived source is retained for reference. Its historical scripts may require path updates and their old environments have been removed.
